Юнит-тесты
==========

В Ü имеется специальный синтаксис для функций юнит-тестов.
Они объявляются с использованием ключевого слова ``fn_test`` с последующим именем в ``()``.

.. code-block:: u_spr

   fn_test( OnePlusTwoTest )
   {
       auto x= 1 + 2;
       halt if( x != 3 );
   }

Функции юнит-тестов могут быть объявлены в корневом пространстве имён, в именованных пространствах, в структурах и классах.
Но не разрешено объявлять юнит-тесты в шаблонах (прямо или косвенно).

Имена юнит-тестов не обязательно должны быть уникальными, дублирование имён для них разрешено.
Компилятор может дать уникальные внутренние имена двум тестам, даже если они имеют одинаковое имя.
Также не возможно обратиться к имени юнит-теста (не возможно вызвать юнит-тест вручную).

Функции юнит-тестов всегда компилируются вместе с файлом, где они объявлены.
Обычно они игнорируются при компоновке и удаляются, так что результирующие скомпилированные файлы не содержат тестов.
Но они используются когда нужно выполнить тестирование, см. :doc:`testing`.
